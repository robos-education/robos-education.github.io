# 프로젝트 스타일 가이드

## 프로젝트 개요
Python class 심화 학습 교안 제작 프로젝트.
각 챕터별 Python 코드(.py)를 먼저 작성/테스트한 뒤, 해당 내용을 기반으로 교안용 Markdown(.md) 파일을 제작한다.

---

## 전체 목차

- Chapter 1 · 상속 심화 (Inheritance Advanced)
- Chapter 2 · 오버라이딩 심화 (Overriding Advanced)
- Chapter 3 · Special Methods (Dunder Method)
- Chapter 4 · 속성 숨기기와 캡슐화
- Chapter 5 · class variable, class method, staticmethod
- Chapter 6 · @property 와 Decorator
- Chapter 7 · 실전 프로젝트 + AI 바이브코딩
- 부록

---

## 소재 및 컨셉
- 게임 캐릭터 / 몬스터 시스템을 주 소재로 사용
- 각 챕터마다 "왜 필요한지" 문제 상황을 먼저 제시
- 실생활·게임 소재로 직관적 이해를 목표로 함

---

## 교안(MD) 작성 규칙

### 구조
1. 챕터 제목 + 소재 + 핵심 질문
2. 개념 설명 (간결한 텍스트)
3. 코드 예제 (Python 코드 블록)
4. 출력 결과 (별도 코드 블록)
5. 핵심 포인트 (> 인용 블록)
6. 도전 과제 (조건 → 예시 답안 → 출력 결과)
7. 챕터 끝에 다음 챕터 예고

### 톤 및 스타일
- 너무 응용해서 꾸미지 않고, 내용과 구조에 충실하게
- 설명은 간결한 평서문 ("~이다", "~한다")
- 불필요한 장식이나 이모지 남용 금지
- 표는 정리용으로만 간결하게 사용

### 코드 규칙
- 코드 주석: 한글
- 변수명, 클래스명, 메서드명: 영문
- 코드 블록과 실행 코드(인스턴스 생성, 호출)는 분리
- 출력 결과는 별도 코드 블록으로 표기

### 품질 관리
- 한글 맞춤법 검수 필수
- 영문 오타 검수 필수 (원본 .py 파일의 오타도 MD에서는 수정 반영)
- 원본 .py 파일에서 발견된 오타는 MD 작업 시 알려주기

---

## 작업 흐름
1. 사용자가 챕터별 .py 파일 업로드
2. 코드 내용과 구조를 그대로 살려서 교안 .md 파일 제작
3. 오타/맞춤법 검수 후 전달
4. 다음 챕터로 이동
